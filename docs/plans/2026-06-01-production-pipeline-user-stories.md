# 自动产制流水线三种模式 User Stories

## 前置条件

用户已经通过“系统自动创作”完成至少一场终稿剧本，并进入该项目的工作流页。验收只覆盖自动产制流水线本身，不重复验证从 0 到剧本的长流程。

## Story 1：快速模式

作为已经完成第一场终稿剧本的用户，我想在“自动产制流水线”里选择“快速模式”，选择已定稿场景，并运行流水线，以便系统为该场创建一组最小产制任务：关键帧任务和视频任务。

验收标准：

1. 用户能在工作流页看到 `自动产制流水线`。
2. 用户能点击 `快速模式`。
3. 用户能关闭 `自动 LLM 质检`、`同步执行图片生成`、`同步执行豆包视频`。
4. 用户能点击 `运行产制流水线`。
5. 页面按钮触发 `/production-pipeline` POST，返回 `201`。
6. 返回结果里的模式是 `quick`，状态是 `completed`，至少包含 1 个视觉资产任务和 1 个视频任务。

## Story 2：导演模式

作为已经完成第一场终稿剧本的用户，我想选择“导演模式”运行自动产制流水线，以便系统为该场创建导演工作包：关键帧、分镜、环境图和视频任务。

验收标准：

1. 用户能点击 `导演模式`。
2. 用户能运行流水线。
3. 页面按钮触发 `/production-pipeline` POST，返回 `201`。
4. 返回结果里的模式是 `director`，状态是 `completed`。
5. 返回结果至少包含 3 个视觉资产任务和 1 个视频任务。

## Story 3：制片模式

作为已经完成第一场终稿剧本的用户，我想选择“制片模式”运行自动产制流水线，以便系统创建更完整的制片工作包：关键帧、分镜、环境图、角色定妆照和视频任务。

验收标准：

1. 用户能点击 `制片模式`。
2. 用户能运行流水线。
3. 页面按钮触发 `/production-pipeline` POST，返回 `201`。
4. 返回结果里的模式是 `producer`，状态是 `completed`。
5. 返回结果至少包含 4 个视觉资产任务和 1 个视频任务。

## 测试约束

- 只通过 Playwright 操作 UI：点击按钮、勾选/取消勾选控件、填写文本。
- 不直接调用业务 API。
- 为避免外部服务不稳定影响流程验收，测试默认关闭真实图片执行和真实豆包视频执行。
- 测试默认关闭自动 LLM 质检，避免质检评分阻断视觉/视频任务创建；质检入口已由上一条 user story 单独覆盖。
